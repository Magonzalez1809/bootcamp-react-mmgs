CSS Basic

Ways to apply styles to our HTML document

  • Inline styles: apply to specific elements when the style attribute is used
  • Element Selectors: apply to specific elements
  • Class: applies to specific elements that have the class attribute, the css class start with a dot ".miclase", you can give more than one element the same class. and you can give more than one class to an element, for example: class="miclase1 miclase2"
  • ID: applies to a specific element that has the id attribute, the css id start with a hash "#miid", please don't give more than one element the same ID, because it will not work properly.
  • Attribute Selectors: applies to specific elements that have a specific attribute, for example, input[type="text"] will apply to all input elements with type text.

Basic styles

  • color:

    to apply color in the font.

  • font-size:

    to specify the size of the font

  • font-family:

    to specify the type of font, you can use google fonts, you can specify more than one font, for example: font-family: Arial, sans-serif; When one font isn't available, you can tell the browser to "degrade" to another font.

  • width:

    to specify the width of the element.

  • border-color, border-style, and border-width, border-radius:

    are properties that control the appearance of CSS borders, you can specify the border in pixels, ems, or percentages. You can also specify the border radius to make the corners rounded.

Padding and Margin

All HTML elements are essentially little rectangles, The padding, border, and margin properties control the space that surrounds each HTML element.
