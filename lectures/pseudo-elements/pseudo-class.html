:hover

If you put the mouse pointer over the element or section you will use the hover pseudo-class, for example, if you want to change the color of a link when the user hovers over it, you can use the :hover pseudo-class.

:active

The :active pseudo-class is used to style an element when it is being activated by the user, for example, when a button is being clicked.

:focus, :focus-within y :focus-visible

The :focus pseudo-class is used to style an element when it has focus, for example, when a user clicks on an input field or a button. The :focus-within pseudo-class is used to style an element when any of its descendants have focus. The :focus-visible pseudo-class is used to style an element when it has focus and the user is using a keyboard or other non-pointer input device.

:target

The :target pseudo-class is used to style an element that is the target of the current URL fragment identifier. Is recommended apply the rule LVHA (link, visited, hover, active) to avoid specificity issues. The order of the pseudo-classes is important because it determines which styles will be applied when multiple pseudo-classes match the same element.

The :disabled pseudo-class is used to style form elements that are disabled, while the :enabled pseudo-class is used to style form elements that are enabled. For example, if you want to change the color of a button when it is disabled, you can use the :disabled pseudo-class.

:checked y :indeterminate

The :checked pseudo-class is used to style checkboxes and radio buttons that are checked. The :indeterminate pseudo-class is used to style checkboxes and radio buttons that are in an indeterminate state.

:placeholder-shown

The :placeholder-shown pseudo-class is used to style input fields that are showing placeholder text. For example, if you want to change the color of an input field when it is showing placeholder text, you can use the :placeholder-shown pseudo-class.
