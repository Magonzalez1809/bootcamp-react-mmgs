Sizing Units

The web is a responsive medium, but sometimes you want to control its dimensions to improve the overall interface quality

Numbers

Numbers are used to define opacity, line-height and even for color channel values in rgb. Numbers are unitless integers (1, 2, 3, 100) and decimals (.1, .2, .3).

If your size is 24px, rather than a specific size. The line height is currently 1.5, which calculates as 36px

The number also use in the follow sities:

  • Fiters: filter:sepia(0.5); apply 50% to element
  • Opacity: opacity:0.5; applay a opcity of 50%
  • Color channels: rgb(50, 50, 50); where the values 0-255 are acceted to apply color value
  • Transform an element: transform: scale(1.2); scales the element by 120% of its initial size.

Percentages

when using a percentage you need to know, how is calculate this. width is calculate of the available width the parent.

The transform is calculated from the elements width, which is 50% of the container’s width.
